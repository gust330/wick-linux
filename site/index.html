Safety

It always puts sleep back.

Forgetting pmset disablesleep 1 is how a laptop cooks in a backpack. So Wick treats turning it off again as the main job.

  1. A guard outlives the app

    Every session is enforced by a small separate process. If the app crashes or the terminal closes, the timer still ends on time.

  2. Low battery stops it

    On battery, Wick lets go at 20% by default, so your Mac can sleep rather than die mid-task.

  3. Heat stops it

    If macOS reports a critical thermal state, the session ends. You can't turn this one off.

  4. Logging out or quitting stops it

    Quit Wick, log out or shut down, and sleep comes back. If the guard is ever force-killed or the power cuts out, a background job picks the session up within five minutes.

  5. The permission is one line

    A sudoers rule that allows two exact commands and nothing else. Read it, or remove it with wick uninstall.

    you ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 0, /usr/bin/pmset -a disablesleep 1

Keep it out of bags while it's awake. A closed Mac sheds heat slowly, and no software fixes that.

By morning the work is done, and your Mac sleeps like normal again.

Install

Four steps, about a minute.

On macOS 14 or later, Apple silicon or Intel. Or on Linux, with systemd.

  1. /01

    Get the app

    Homebrew is the easiest way to install and update Wick, and it adds the wick command too.

    brew install --cask s1lvazxy/tap/wick

    Update with brew upgrade --cask wick.

    Download from GitHub

    Unzip and drag Wick to Applications. Early builds aren't notarised, so the first time, open System Settings → Privacy & Security and choose Open Anyway.

    pipx install "git+https://github.com/s1lvazxy/wick@v0.2.0#subdirectory=linux" && wick setup

    Adds a top bar extension on GNOME, or run wick app elsewhere. Needs systemd-logind, and no root at all, so step 3 below doesn't apply. There's also an RPM.

  2. /02

    Open it and press play

    Wick lives in your menu bar or top bar, with no window of its own. Click the mark, pick a duration, press play.

  3. /03

    Allow it, once

    On a Mac, only an admin can keep a closed Mac awake, so the first time, macOS asks for your password to add Wick's one-line rule. You won't be asked again. Linux skips this step.

  4. /04

    Close the lid

    That's it. Open it again whenever you like. The panel tells you how long is left, or why Wick stopped.

From the terminal

wick on 2h
Stay awake for two hours.
wick on --agents
Stay awake until your agents finish.
wick run claude
Stay awake while one command runs.
wick off
Back to normal, right now.
wick status
See what's going on.

Questions

Why not just use caffeinate?

caffeinate stops idle sleep, but closing the lid still puts the Mac to sleep. Only the disablesleep setting survives that, and it needs root.

What counts as an agent finishing?

Its process exiting. An agent left open at its prompt still counts as running, so use a timer or wick run if that's likely.

Do I need an external display or power?

Neither. It works on battery with nothing plugged in, and stops at the battery level you choose.

Does it work over SSH on Linux?

Only with a one-line polkit rule, because logind normally gives this lock to the person at the laptop. wick doctor prints the rule.

How do I remove it?

Run wick uninstall, then brew uninstall --cask wick or pipx uninstall wick-linux, or delete the app if you installed it by hand.
